# 模型配置说明

通过服务端环境变量配置兼容的模型接口：`TJUSAI_API_KEY`、`TJUSAI_BASE_URL` 和 `TJUSAI_MODEL`。`.env.example` 提供供应商公开接口的示例值，部署者应使用自己的密钥和有权限调用的模型。

密钥只留在服务端。浏览器不能编辑任意上游地址，也不会获得请求凭据。模型是否可用、流式格式、输出上限和计费规则，均需要部署者向服务商确认，并用合成内容进行小额验证。

## 上下文预算

`REQUEST_TOKEN_BUDGET` 是本应用的保护预算，不是供应商的能力承诺。应用使用保守估算检查参考章节、当前分支、指令及输出预算；超出预算时要求调整范围，不静默截掉所选正文。token数不等于汉字数，估算不能替代供应商tokenizer。

只有取得所配置接口的有效限制证据后，才填写 `MODEL_CONTEXT_LIMIT` 并设置 `MODEL_CONTEXT_VERIFIED=true`。第三方中转可能具有与上游不同的限制，不能仅凭模型名称或上游公开规格推定实际接口支持百万上下文。

## 故障与隐私

- 先检查模型列表与访问权限，再用少量合成内容验证system、多轮和流式格式；不要把真实稿件放进公开测试报告。
- 失败、取消、空正文或不完整返回不得自动写入原稿。
- 取消会尽力中止上游请求；已经处理的内容是否计费由服务商决定。
- 请求日志只保留状态和用量等必要元数据，不记录密钥或完整稿件。
